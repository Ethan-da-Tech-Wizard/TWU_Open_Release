# Code of conduct

Be straightforward and kind. Argue about code and claims, not about people.

- Report problems with evidence, not accusations. "This claim is not supported by this test" is welcome; personal remarks are not.
- Assume good faith, and say so when you are unsure.
- No harassment, discrimination, threats, or sharing other people's private information.
- Keep issues and pull requests on topic.

I may edit, hide or delete comments, close issues, or block users that break these rules. To report a conduct problem privately, use the repository's **Security** tab, **Report a vulnerability**, and start the title with "Conduct". I have no email address for this on purpose.

This applies in the repository's issues, pull requests and discussions.
